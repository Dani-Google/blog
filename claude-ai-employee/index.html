I Turned Claude Into My Full-Time AI Employee. This Is the Exact Prompt Stack I Use.

Short answer: Every business has that one task. The one that eats an hour every single day, the same clicks, the same copy-paste, the same follow-ups. I used to accept it as the cost of running things.

Every business has that one task. The one that eats an hour every single day, the same clicks, the same copy-paste, the same follow-ups. I used to accept it as the cost of running things. Then I stopped doing it myself — and I didn't hire anyone either.

I gave the whole workflow to Claude. Not as a chatbot. As an employee.

The Prompt

Pick one repetitive workflow your business handles every day, then paste this into Claude:

Act as an AI automation architect. Here's a task my business handles every day: [task]. Design an end-to-end automation using n8n, APIs, and AI agents. Include triggers, integrations, decision logic, error handling, and estimated costs. Give me a step-by-step implementation plan with minimal manual work.

Replace [task] with your actual workflow, in plain words. "Every morning I check Gmail for new orders, copy them into a sheet, and message the customer on WhatsApp." That's enough.

What You Get Back

Claude hands you a complete plan, not a vague idea:

  • Triggers — what starts the automation (a new email, a form submission, a time of day)
  • Integrations — which tools connect to which, and how
  • Decision logic — what happens when things go the normal way, and when they don't
  • Error handling — what the system does when an API fails or data is missing
  • Estimated costs — what the whole thing costs to run each month
  • Step-by-step implementation — in order, with minimal manual work

How I Actually Use It

One workflow at a time. I never hand Claude five processes at once — the plan gets generic and I stop trusting it. I pick the single most repetitive task, get the plan, build it in n8n, and let it run for a week before touching the next one.

Two things I check before building: the cost estimate (n8n self-hosted is free, the cloud version and the APIs are not), and the error handling (an automation that silently fails is worse than no automation at all).

The Shift

The point was never the prompt. The point is the question it forces you to answer: which task am I repeating every day that a system could do instead? Once you name it, the automation is the easy part.

Start with one task. Today.
